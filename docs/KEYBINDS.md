# Keybindings

ARCHMAC uses SUPER as its primary shell modifier.

## Applications and Galaxy

- SUPER + Q — terminal
- SUPER + E — file manager
- SUPER + R — Galaxy launcher
- SUPER + D — Galaxy Command Centre
- SUPER + TAB — spatial workspace overview
- SUPER + ESCAPE — session / power menu
- SUPER + C — close active window
- SUPER + V — toggle floating
- SUPER + F — fullscreen
- SUPER + L — lock

## Clipboard

- SUPER + SHIFT + V — legacy clipboard-history fallback

Searchable clipboard history is also available through Galaxy Launcher.

## Workspaces

- SUPER + 1..0 — switch workspace
- SUPER + CTRL + 1..0 — move active window
- SUPER + arrows — change focus
- SUPER + mouse wheel — cycle workspaces
- SUPER + S — toggle special workspace
- SUPER + SHIFT + S — move window to special workspace

Workspace gestures are handled by Hyprland.

## Screenshots

- SUPER + SHIFT + 3 — full screen
- SUPER + SHIFT + 4 — select region

Screenshots are stored under ~/Pictures/Screenshots.

## ARCHMAC modes

- SUPER + F12 — mode cycle
- SUPER + SHIFT + F12 — Battery
- SUPER + CTRL + F12 — Fancy

## Multimedia

Hardware keys control audio, microphone mute, display brightness,
keyboard illumination where supported, and media playback.
