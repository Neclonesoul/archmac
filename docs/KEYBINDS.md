# Keybindings

ARCHMAC uses `SUPER` as its primary modifier.

## Applications

- `SUPER + Q` — terminal
- `SUPER + E` — file manager
- `SUPER + R` — application launcher
- `SUPER + C` — close active window
- `SUPER + V` — toggle floating
- `SUPER + F` — fullscreen
- `SUPER + L` — lock

## Workspaces

- `SUPER + 1..0` — switch workspace
- `SUPER + CTRL + 1..0` — move active window to workspace
- `SUPER + arrows` — change window focus
- `SUPER + S` — toggle special workspace
- `SUPER + SHIFT + S` — move window to special workspace

`SUPER + CTRL + number` is intentionally used for moving windows so
the macOS-style screenshot shortcuts remain available.

## Screenshots

- `SUPER + SHIFT + 3` — full-screen screenshot
- `SUPER + SHIFT + 4` — interactive region screenshot

Screenshots are saved under `~/Pictures/Screenshots`.

## ARCHMAC modes

- `SUPER + F12` — toggle Fancy / Performance

## Multimedia

Hardware media keys control:

- speaker volume
- speaker mute
- microphone mute
- display brightness
- keyboard illumination
- media playback
