# Contributing to ARCHMAC

ARCHMAC is the canonical configuration of a real MacBookPro9,2 workstation.

Changes should optimise for correctness, reproducibility, recoverability and
simplicity.

Before changing behaviour:

1. inspect current state;
2. identify the actual problem;
3. keep scope small;
4. preserve working behaviour;
5. verify the result;
6. document meaningful changes.

Pull requests should explain the problem, change, verification and rollback path.

Never submit credentials or secrets.
