# Changelog

## v1.0.1

- add `archmac-wallpaper` wallpaper manager
- add Thunar **Set as ARCHMAC Wallpaper** action
- persist selected wallpapers in ARCHMAC-managed storage
- support PNG, JPG/JPEG, and WebP wallpapers
- document wallpaper workflow

## v1.0.0

Initial known-good ARCHMAC baseline.

- Arch Linux + Hyprland workstation
- MacBookPro9,2 hardware integration
- Fancy / Performance / Battery modes
- Waybar desktop instrumentation
- Kitty terminal configuration
- Hyprlock / Hypridle / Hyprpaper
- Apple keyboard illumination controls
- display brightness controls
- multimedia controls
- macOS-style screenshot workflow
- workspace workflow without screenshot collisions
- clipboard history
- GTK3 / GTK4 dark integration
- Qt Wayland integration
- safe backup-first installer
- documented recovery doctrine
